## 想定問題の追加・修正のしかた

1. `questions/yosou.csv` をスプレッドシート（Googleスプレッドシート、Excel、Numbersなど）で開いて、行を追加・修正する。
2. `python3 tools/build.py` を実行する。入力ミスがあればエラーが出る。問題なければ `questions/yosou.md` が更新される。

### CSVの列

| 列 | 書き方 |
|---|---|
| ID | ジャンル記号＋連番。KO＝ことば、CR＝地理・歴史、SE＝政治・経済、SH＝社会、KK＝国際、SZ＝自然科学、SK＝生活、SP＝スポーツ、GJ＝芸術、CU＝カルチャー（例：`KO-011`） |
| バッチ | 作った回（`batch01` など） |
| ジャンル | 10ジャンルのどれか（公式の表記どおり） |
| 指標 | 基礎学力／社会生活力／語彙力／推察力／分析力／時事力 |
| 難易度 | A（基礎）／B（標準）／C（難） |
| 問題文 | 公式に合わせて「〜は何か。」「〜はどれか。」の形にする |
| 選択肢1〜4 | Xの投票に載せるため、25文字以内 |
| 正解 | 正しい選択肢の番号（1〜4） |
| 解説 | 正解の根拠と、話したくなる小ネタ |
| 出典URL | 信頼できる出典（Wikipediaは不可）。複数あるときは `\|` で区切る |
| 時点 | 時事問題のとき、いつ時点の情報か（例：`2025年10月`） |
| ステータス | 下書き → 確認済（事実確認と出典URLがそろった）→ 採用（公開してよい）。内容は確認済みで出典URLだけ未取得のものは 出典待ち。ほかに 要修正／不採用 |
| 作問者 | Claude／自分の名前 |
| X投稿日・X正答率 | Xで出題したら記録する（ブログ掲載時に「正答率◯%」として使う） |

作問のルール（配分・文体・選択肢の作り方）は [docs/03_trends-and-strategy.md の「4. 想定問題の作り方」](docs/03_trends-and-strategy.md#4-想定問題の作り方このリポジトリのルール) にまとめている。

## 注意

- 他サイトや公式の問題は分析用に要旨だけを記録している。ブログやXで公開するのは、このリポジトリのオリジナル問題だけにする。
- 公式と誤解されないよう、発信するときは「非公式」と明記する。
