## 試験形式

| 項目 | 内容 |
|---|---|
| 出題形式 | **4肢択一** |
| 問題数 | **500問**（10ジャンル×50問） |
| 試験時間 | **110分**（1問あたり約13秒） |
| 級 | 1階級のみ |
| 合格基準 | **全10ジャンルそれぞれで40%（20問）以上**、かつ**全体で70%（350問）以上** |
| 成績表 | 「知歴書」：ジャンルごとの偏差値など、知識の偏りがわかる |
| その他 | ジャンルごとに成績上位100名を発表 |

※初期の回は「1級：1000問・300分」という形式だった（受検者の体験記より）。現在は1階級・500問・110分。

### 『知識検定事典』から分かる問題の設計

PART2の「指標」は、試験がジャンルとは別の軸でも問題を設計していることを示している。

- **基礎学力**
- **社会生活力**
- **語彙力**
- **推察力**
- **分析力**
- **時事力**
- **画像問題**（オンライン受検なので画像を見て答える問題がある）

このリポジトリの想定問題も、この「指標」と難易度で分類している。
