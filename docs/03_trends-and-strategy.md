# 傾向と対策

最終更新：2026-10-03

根拠の強さを区別するため、次の印を付けている。

- **【事実】**：公式情報・公式例題・受検者の体験記で確認済み
- **【公式X】**：公式X（@Chishikikentei）の例題1128問（2018年8月〜2022年12月、第1〜5回向け）の集計。問題・選択肢・正解は公式の投稿どおりだが、ジャンル（2019年3月以降は投稿に書かれていない）と時事かどうかは当方の判断
- **【データ】**：covez の予想問題230問の集計（第1回から毎年合格している人の予想で、本試験の問題そのものではない）
- **【推測】**：現時点の材料からの見立て。過去問で要検証

covez と公式Xで違うところは、**公式Xを優先**する。集めた問題の一覧は [questions/collected.md](../questions/collected.md)。

## 1. 出題の傾向

### 1-1. 形式からくる特徴

- **【事実】4肢択一・500問・110分。** 1問あたり約13秒しかない。じっくり考える問題より、**見た瞬間に分かるかどうか**の問題が中心になる。
- **【事実】オンライン受検**（第5回から）。『知識検定事典』に「画像問題」の区分があり、画像を見て答える問題も出る。
- **【公式X】問題文も選択肢も短い。** 問題文は中央値27字で、9割が39字以内（最長60字）。選択肢は中央値4字で、95%が10字以内（最長23字）。**選択肢は単語1つが基本**で、文章の選択肢は「意味はどれか」「説明として正しいのは」の問題に限られる。
- **【公式X】** 数値の選択肢は38問中37問が小さい順。正解の位置は1〜4番でほぼ均等（280／265／219／232問）。

### 1-2. 合否を分けるのは「足切り」

- **【事実】合格には、全10ジャンルそれぞれで20問（40%）以上、全体で350問（70%）以上が必要。** 第7回の合格率は45.4%。
- **【事実】** 第7回の合格者の一例では、スポーツがちょうど20点で、足切りすれすれだった（冬季スポーツに苦戦）。この人は過去2回、**時事に足を引っ張られた**とも書いている。
- **【事実】** 第1回から毎年合格している人でも正答率は8割前後。
- **【推測】** 総合点は足りているのに、苦手な1ジャンルで落ちる人が多いと思われる。

### 1-3. 問題はジャンル以外の軸でも設計されている

- **【事実】**『知識検定事典』は過去問を「ジャンル別・難易度別」に加え、**「指標別」（基礎学力・社会生活力・語彙力・推察力・分析力・時事力）**でも分類している。

## 3. 受検者向けの対策（ブログ記事の柱にできる内容）

1. **苦手ジャンルを先に20点まで上げる。** 足切りがある以上、得意ジャンルを伸ばすより先に苦手をなくす方が合格に近い。まず公式アプリの無料問題で、ジャンル別の弱点を確認する。
2. **時事は1年分をまとめて確認する。** スポーツ・カルチャー・国際は半分以上が時事になりうる。『現代用語の基礎知識』を読んで対策した合格者もいる。
3. **過去問は『知識検定事典』と公式アプリで解く。** 事典には正答率が付いているので、「正答率が高いのに解けなかった問題」から優先して復習する。
4. **1問13秒に慣れる。** 4択を声に出さずに即答する練習。迷った問題に時間をかけない。
5. **消去法を使う。** 「推察力」を問う問題は、知らなくても選択肢から絞り込める。
6. **冬季スポーツと、カルチャーの新しい話題は手薄になりがち。** 意識して触れておく。

## 4. 想定問題の作り方（このリポジトリのルール）

### 配分

- **ジャンル**：10ジャンル均等（バッチごとに各ジャンル同数）。
- **難易度**：全体では A（基礎）：B（標準）：C（難）＝ **3.5:4.5:2** 前後を目安にする（1-6）。
- **時事**：全体では **2割前後**を目安にする（公式例題11%と covez 30%の間。1-4）。ジャンルごとの濃淡は公式Xの順に合わせる。

| ジャンル | 時事の目安（1バッチ10問あたり） |
|---|---|
| スポーツ・カルチャー | 3〜7問 |
| 国際 | 3〜5問 |
| 社会・政治・経済 | 2〜4問 |
| 自然科学・生活・芸術・地理歴史 | 0〜1問 |
| ことば | 0問 |

- **指標**：ことばは語彙力中心、生活・社会は社会生活力を多めに。推察力・分析力の問題も混ぜる。

#### バッチごとの配分

| 項目 | 第1弾（batch01） | 第2弾（batch02） | 2バッチの合計 | 全体の目安 |
|---|---|---|---|---|
| 時事 | 12%（12問） | **30%（30問）** | 21% | 2割前後 |
| A:B:C | 50:46:4 | **30:40:30** | 40:43:17 | 35:45:20 |

**第2弾は、第1弾で足りなかった時事と難問を補う回にする。** 時事30問の内訳は、スポーツ7・カルチャー6・国際5・社会4・政治経済3・生活2・自然科学1・芸術1・地理歴史1・ことば0。

### 文体（公式例題に合わせる）

- 常体で、文末は「〜は何か。」「〜はどれか。」「〜は誰か。」「〜はどこか。」。【公式X】の文末は「何か」22%・「どれか」18%・「どこか」13%・「誰か」12%、ほかは「何県か」「何の競技の選手か」「何というか」のように中身を絞った形。
- 選択肢から選ぶ形は「次のうち、〜はどれか。」（公式Xの13%）。「〜でないのはどれか」「誤っているのはどれか」の否定形は4%しかないので、**1バッチ5問以内**にする。
- 問題文は**40字以内**を目安にする（公式Xの9割が39字以内）。説明が長くなる問題は、前置きを削る。
- 時事問題は「2025年10月、」のように年月を入れ、`時点` 列にも記録する。統計は「（2025年）」のように年を添える。今の状態を問うときは「現在の〜」「（2026年10月時点）」と書く。
- 読みの問題は例文を付けて、読みを一つに絞る（例：「貸し借りを相殺する」というときの「相殺」）。
- ジャンルは公式の線引きに合わせる（1-5）。特に、観光地・景勝地・祭りはカルチャー、伝統芸能・文学・食器ブランドは芸術、パソコン・ネットの操作は生活、勲章・資格・宗教・ビジネス用語は社会。

### 選択肢

- 4つとも同じ種類（人名なら人名、年なら年）にそろえる。
- **単語1つの短い選択肢を基本にする**（公式Xは中央値4字、95%が10字以内）。Xの投票機能の上限は25字。
- 数値・年・日付は小さい順に並べる（公式Xも38問中37問が小さい順）。それ以外は、正解の位置が偏らないように散らす。
- 「本来の意味」を問う問題は、よくある誤用を誤答に入れる。
- **別解の芽をつぶす。** 解釈次第で正解になる選択肢を入れない（例：「香の物」の誤答に「漬け物の一種」を入れない）。
- 問題文はハッシュタグ込みで140字以内に収める。
- **集めた問題（公式例題を含む）と同じ題材はそのまま使わない**（`questions/collected.csv` と照らし合わせる）。

### 事実確認

- 解説の事実まで含めて、作問者とは別のエージェントが確認する。
- 出典は公式・公的機関・新聞・専門機関・辞書などに限る（Wikipediaは不可）。
- 時事問題は、公開する直前にもう一度確認する。

### 流れ

1. Claude が作問（`ステータス`＝下書き）
2. 別のエージェントが事実確認（＝確認済／出典待ち／要修正）
3. あなたが確認して採用を決める（＝採用）
4. X に投票形式で出題し、投稿日と正答率を記録
5. ジャンル別にまとめてブログに掲載（正答率つき）
