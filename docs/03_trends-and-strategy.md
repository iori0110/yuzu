# 傾向と対策

最終更新：2026-10-02

根拠の強さを区別するため、**【事実】**（公式情報・公式例題・受検者の体験記で確認済み）と、**【推測】**（現時点の材料からの見立て。過去問で要検証）を付けている。

---

## 1. 出題の傾向

### 1-1. 形式からくる特徴

- **【事実】4肢択一・500問・110分。** 1問あたり約13秒しかない。じっくり考える問題より、**見た瞬間に分かるかどうか**の問題が中心になる。
- **【事実】オンライン受検。** 『知識検定事典』に「画像問題」の区分があり、画像を見て答える問題も出る。
- **【推測】** 13秒で解ける長さに収めるため、問題文は短い（公式例題は2問とも40字前後）。

### 1-2. 合否を分けるのは「足切り」

- **【事実】合格には、全10ジャンルそれぞれで20問（40%）以上、全体で350問（70%）以上が必要。** 第7回の合格率は45.4%。
- **【事実】** 第7回の合格者の一例では、スポーツがちょうど20点で、足切りすれすれだった（冬季スポーツに苦戦）。
- **【推測】** 総合点は足りているのに、苦手な1ジャンルで落ちる人が多いと思われる。スポーツ・カルチャー（芸能・サブカル）・生活は、得意な人と苦手な人の差が大きいジャンル。

### 1-3. 問題はジャンル以外の軸でも設計されている

- **【事実】**『知識検定事典』は過去問を「ジャンル別・難易度別」に加え、**「指標別」（基礎学力・社会生活力・語彙力・推察力・分析力・時事力）**でも分類している。
- **【推測】** 各ジャンルの中に、「知っていれば解ける基礎問題」「暮らしの常識」「時事」「選択肢から推理できる問題」が混ぜてある。

### 1-4. 時事問題

- **【事実】** 公式例題に「2026年、GDPで日本を抜いて世界4位となる見込みの国」があり、時事力を問う問題は年を明記して出す。
- **【推測】** 2月の本試験では、**前年（第9回なら2026年）の出来事**が中心になる。問題の作成時期を考えると、2026年11月ごろまでの出来事が対象になりやすい。

### 1-5. ことば

- **【事実】** 公式例題に「反故」の読みがある。対策ブログでもことわざの穴埋めが出ている。
- **【推測】** 読み（難読語・誤読しやすい語）、慣用句やことわざの本来の意味、四字熟語が柱。文化庁「国語に関する世論調査」で取り上げられる「誤用されやすい言葉」は狙い目。

### 1-6. 難易度の幅

- **【事実】** 受検者の多くが「クイズ番組のようなマニアックな問題も多い」「堅い問題から軽い話題まで幅広い」と書いている。
- **【推測】** 合格率45%・合格ライン70%から見て、**誰でも解ける問題、受検者の半分くらいが解ける問題、クイズ愛好家でも迷う問題**が、だいたい3:4:3で混ざっている。

### 1-7. 各ジャンルの範囲（見立て）

## 3. 受検者向けの対策（ブログ記事の柱にできる内容）

1. **苦手ジャンルを先に20点まで上げる。** 足切りがある以上、得意ジャンルを伸ばすより先に苦手をなくす方が合格に近い。まず公式アプリの無料問題で、ジャンル別の弱点を確認する。
2. **過去問は『知識検定事典』と公式アプリで解く。** 事典には正答率が付いているので、「正答率が高いのに解けなかった問題」から優先して復習する。
3. **時事は1年分をまとめて確認する。** 12月〜1月に、その年の出来事をジャンル別に振り返る。
4. **1問13秒に慣れる。** 4択を声に出さずに即答する練習。迷った問題に時間をかけない。
5. **消去法を使う。** 「推察力」を問う問題は、知らなくても選択肢から絞り込める。
6. **冬季スポーツと、カルチャーの新しい話題は手薄になりがち。** 意識して触れておく。

## 4. 想定問題の作り方（このリポジトリのルール）

### 配分

- **ジャンル**：10ジャンル均等（バッチごとに各ジャンル同数）。
- **難易度**：A（基礎）：B（標準）：C（難）＝ **3:4:3** を目標にする。
  - ※第1弾（batch01）はA・B中心でCが少ない。X での出題に向く「解けそうで迷う」水準から始め、第2弾以降でCを増やす。
- **指標**：時事力を各ジャンル1〜2問、ことばは語彙力中心、生活・社会は社会生活力を多めに。推察力・分析力の問題も混ぜる。

### 文体（公式例題に合わせる）

- 常体で、文末は「〜は何か。」「〜はどれか。」「〜は誰か。」「〜はどこか。」。
- 時事問題は「2025年10月、」のように年月を入れ、`時点` 列にも記録する。
- 読みの問題は例文を付けて、読みを一つに絞る（例：「貸し借りを相殺する」というときの「相殺」）。

### 選択肢

- 4つとも同じ種類（人名なら人名、年なら年）にそろえる。
- 数値・年・日付は小さい順に並べる。それ以外は、正解の位置が偏らないように散らす。
- 「本来の意味」を問う問題は、よくある誤用を誤答に入れる。
- **別解の芽をつぶす。** 解釈次第で正解になる選択肢を入れない（例：「香の物」の誤答に「漬け物の一種」を入れない）。
- **Xの投票機能に載せられるよう、選択肢は25字以内。** 問題文はハッシュタグ込みで140字以内に収める。

### 事実確認

- 解説の事実まで含めて、作問者とは別のエージェントが確認する。
- 出典は公式・公的機関・新聞・専門機関・辞書などに限る（Wikipediaは不可）。
- 時事問題は、公開する直前にもう一度確認する。

### 流れ

1. Claude が作問（`ステータス`＝下書き）
2. 別のエージェントが事実確認（＝確認済／要修正）
3. あなたが確認して採用を決める（＝採用）
4. X に投票形式で出題し、投稿日と正答率を記録
5. ジャンル別にまとめてブログに掲載（正答率つき）
