# 傾向と対策

最終更新：2026-10-03

根拠の強さを区別するため、次の印を付けている。

- **【事実】**：公式情報・公式例題・受検者の体験記で確認済み
- **【データ】**：covez の予想問題230問の集計（第1回から毎年合格している人の予想で、本試験の問題そのものではない）
- **【推測】**：現時点の材料からの見立て。過去問で要検証

集めた問題の一覧は [questions/collected.md](../questions/collected.md)。

## 1. 出題の傾向

### 1-1. 形式からくる特徴

- **【事実】4肢択一・500問・110分。** 1問あたり約13秒しかない。じっくり考える問題より、**見た瞬間に分かるかどうか**の問題が中心になる。
- **【事実】オンライン受検**（第5回から）。『知識検定事典』に「画像問題」の区分があり、画像を見て答える問題も出る。
- **【事実】** 公式例題は2問とも40字前後と短い。

### 1-2. 合否を分けるのは「足切り」

- **【事実】合格には、全10ジャンルそれぞれで20問（40%）以上、全体で350問（70%）以上が必要。** 第7回の合格率は45.4%。
- **【事実】** 第7回の合格者の一例では、スポーツがちょうど20点で、足切りすれすれだった（冬季スポーツに苦戦）。この人は過去2回、**時事に足を引っ張られた**とも書いている。
- **【事実】** 第1回から毎年合格している人でも正答率は8割前後。
- **【推測】** 総合点は足りているのに、苦手な1ジャンルで落ちる人が多いと思われる。

### 1-3. 問題はジャンル以外の軸でも設計されている

- **【事実】**『知識検定事典』は過去問を「ジャンル別・難易度別」に加え、**「指標別」（基礎学力・社会生活力・語彙力・推察力・分析力・時事力）**でも分類している。

### 1-4. 時事問題の比重が高い（いちばん大事な傾向）

- **【事実】** 公式例題の2問のうち1問が時事（「2026年、GDPで日本を抜いて世界4位となる見込みの国」）。時事問題は年を明記して出す。

- **【事実】** 受検者の多くが「クイズ番組のようなマニアックな問題も多い」「堅い問題から軽い話題まで幅広い」と書いている。

## 3. 受検者向けの対策（ブログ記事の柱にできる内容）

1. **苦手ジャンルを先に20点まで上げる。** 足切りがある以上、得意ジャンルを伸ばすより先に苦手をなくす方が合格に近い。まず公式アプリの無料問題で、ジャンル別の弱点を確認する。
2. **時事は1年分をまとめて確認する。** スポーツ・カルチャー・国際は半分以上が時事になりうる。『現代用語の基礎知識』を読んで対策した合格者もいる。
3. **過去問は『知識検定事典』と公式アプリで解く。** 事典には正答率が付いているので、「正答率が高いのに解けなかった問題」から優先して復習する。
4. **1問13秒に慣れる。** 4択を声に出さずに即答する練習。迷った問題に時間をかけない。
5. **消去法を使う。** 「推察力」を問う問題は、知らなくても選択肢から絞り込める。
6. **冬季スポーツと、カルチャーの新しい話題は手薄になりがち。** 意識して触れておく。

## 4. 想定問題の作り方（このリポジトリのルール）

### 配分

- **ジャンル**：10ジャンル均等（バッチごとに各ジャンル同数）。
- **難易度**：A（基礎）：B（標準）：C（難）＝ **3:4:3** を目標にする。
- **時事**：全体の3割を目標に、ジャンルごとの割合を【データ】に合わせる（スポーツ・カルチャーは6〜7割、国際は5割、社会は4割、政治・経済は3割、生活は2割、ほかは1割未満）。
- **指標**：ことばは語彙力中心、生活・社会は社会生活力を多めに。推察力・分析力の問題も混ぜる。

#### 第1弾（batch01）の過不足

| 項目 | 第1弾 | 目標 |
|---|---|---|
| 時事 | 12%（12問） | 30% |
| 難（C） | 4% | 30% |

**第2弾は、スポーツ・カルチャー・国際・社会を中心に2025年秋〜2026年の時事を増やし、難問も増やす。**

### 文体（公式例題に合わせる）

- 常体で、文末は「〜は何か。」「〜はどれか。」「〜は誰か。」「〜はどこか。」。
- 時事問題は「2025年10月、」のように年月を入れ、`時点` 列にも記録する。
- 読みの問題は例文を付けて、読みを一つに絞る（例：「貸し借りを相殺する」というときの「相殺」）。

### 選択肢

- 4つとも同じ種類（人名なら人名、年なら年）にそろえる。
- 数値・年・日付は小さい順に並べる。それ以外は、正解の位置が偏らないように散らす。
- 「本来の意味」を問う問題は、よくある誤用を誤答に入れる。
- **別解の芽をつぶす。** 解釈次第で正解になる選択肢を入れない（例：「香の物」の誤答に「漬け物の一種」を入れない）。
- **Xの投票機能に載せられるよう、選択肢は25字以内。** 問題文はハッシュタグ込みで140字以内に収める。
- **集めた予想問題と同じ題材はそのまま使わない**（`questions/collected.csv` と照らし合わせる）。

### 事実確認

- 解説の事実まで含めて、作問者とは別のエージェントが確認する。
- 出典は公式・公的機関・新聞・専門機関・辞書などに限る（Wikipediaは不可）。
- 時事問題は、公開する直前にもう一度確認する。

### 流れ

1. Claude が作問（`ステータス`＝下書き）
2. 別のエージェントが事実確認（＝確認済／出典待ち／要修正）
3. あなたが確認して採用を決める（＝採用）
4. X に投票形式で出題し、投稿日と正答率を記録
5. ジャンル別にまとめてブログに掲載（正答率つき）
